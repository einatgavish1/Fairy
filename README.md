# Fairy · קליטת מסמכים

אפליקציית ווב לרואת חשבון: מעלים חשבוניות וקבלות (PDF או תמונה), והאפליקציה מזהה בהן
תאריך, סכום, מע"מ, שם הספק, ח.פ / ע.מ, סוג ומספר מסמך וסוג השירות. אפשר לתקן, לשמור,
לסנן לפי לקוח / חודש / סוג שירות, לראות סיכום שנתי ולייצא לאקסל.

- זיהוי הטקסט רץ בדפדפן: pdf.js ל-PDF עם טקסט, Tesseract.js (עברית + אנגלית) לתמונות ולסריקות.
- הנתונים ב-Firestore של הפרויקט `fairy-36dc8` (אוסף `docs`, תמונות קטנות ב-`previews`).
- כניסה עם Google; הבעלים משתפים מיילים נוספים מכפתור "שיתוף".
- כל עוד `apiKey` ב-`firebase-config.js` ריק, האפליקציה עובדת במצב מקומי (שמירה בדפדפן בלבד).

פריסת הכללים: `npx firebase-tools deploy --only firestore:rules`
